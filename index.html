Agents in fixed roles for planning, implementation and review, with defined handovers. A human approves risky changes, merges follow a human review. I let agents test the same way: several roles, every finding backed by evidence. The figures are under projects.

Agentischer Entwicklungsprozess im TeamAn agentic development process for the team

Bei SPIRIT-TESTING, Herbst 2026. Sechs Stufen vom Ticket bis zur Abnahme, Agenten in getrennten Rollen, Freigabe und Merge durch Menschen. Vorher und nachher mit denselben Kennzahlen gemessen: siebenmal so viele Pull Requests je Woche, 72 % weniger Änderungswünsche je Pull Request, bei etwa gleicher Größe der Änderungen.

At SPIRIT-TESTING, autumn 2026. Six stages from ticket to sign-off, agents in separate roles, human approval and merge. Measured before and after with the same figures: seven times as many pull requests per week, 72 % fewer change requests per pull request, with the size of the pull requests roughly unchanged.
