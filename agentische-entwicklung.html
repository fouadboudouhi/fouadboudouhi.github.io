Sechs Stufen mit festen Übergaben, und eine Messung vorher und nachher. Six stages with fixed handovers, and a measurement before and after.

Mit KI-Werkzeugen entwickelt hat das Team schon, bevor ich im Juli 2026 dazukam. Einen gemeinsamen Ablauf dafür gab es nicht. Ich habe deshalb den Weg vom Ticket bis zum Merge in sechs Stufen zerlegt und für jede festgelegt, was sie an die nächste übergibt. Das Produkt ist ein Testmanagement-Werkzeug, das Team besteht aus vier Entwicklern, der Code liegt in einem Repository.

The team was already using AI tools when I joined in July 2026. It had no shared process for them. So I split the path from ticket to merge into six stages and defined what each one hands to the next. The product is a test management tool, the team is four developers, the code lives in one repository.

Die Agenten arbeiten in getrennten Rollen für Planung, Umsetzung und Review, mit definierten Übergaben dazwischen. An zwei Stellen steht ein Mensch im Ablauf: Riskante Änderungen gibt jemand aus dem Team frei, und gemergt wird erst nach einem menschlichen Review. Eine eigene Sicherheitsprüfung läuft vor der Abnahme. Die Regeln dafür habe ich aufgeschrieben und das Team darin eingearbeitet.

The agents work in separate roles for planning, implementation and review, with defined handovers in between. A human is in the loop at two points: someone on the team approves risky changes, and nothing is merged without a human review. A dedicated security check runs before sign-off. I wrote the rules down and onboarded the team.

Gemessen habe ich an den gemergten Pull Requests des Repositories, ausgelesen aus GitHub. Vorher sind 27 Wochen mit 721 Pull Requests, nachher drei Wochen mit 407. Die Kennzahlen sind in beiden Zeiträumen dieselben: Pull Requests je Woche, Zeit bis zum Merge, Änderungswünsche und Nachbesserungsrunden je Pull Request, Bug-Tickets je Pull Request und die Größe der Änderungen.

I measured on the repository's merged pull requests, pulled from GitHub: 27 weeks and 721 pull requests before, three weeks and 407 after. The metrics are the same for both periods: pull requests per week, time to merge, change requests and rework rounds per pull request, bug tickets per pull request, and the size of the changes.

Der Durchsatz hat sich verfünffacht, und die Pull Requests brauchen weniger Korrekturen: 72 % weniger Änderungswünsche, halb so viele Nachbesserungsrunden und halb so viele Bug-Tickets je Pull Request. Die Gegenprobe ist die Größe der Änderungen. Sie liegt mit 578 Zeilen im Median leicht über den 522 von vorher. Der Durchsatz kommt also nicht daher, dass die Arbeit in mehr Stücke geschnitten wurde.

Throughput went up fivefold, and the pull requests need fewer corrections: 72 % fewer change requests, half the rework rounds and half the bug tickets per pull request. The counter-check is the size of the changes: a median of 578 lines, slightly above the 522 before. So the throughput did not come from slicing the work into smaller pieces.

Drei Wochen gegen 27 bleiben eine dünne Vergleichsbasis. In die drei Wochen fiel außerdem ein großes Vorhaben, das einen Teil des Sprungs erklären kann. Die Zahlen hier sind der Stand vom 09.10.2026.

Three weeks against 27 is still a thin baseline. A large piece of work also fell into those three weeks, which may explain part of the jump. The figures here are as of 9 October 2026.
