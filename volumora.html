Die AppThe app

Volumora ist eine Trainings-App fürs Handy: Pläne anlegen, im Studio Sätze abhaken, den Fortschritt sehen. Der Maßstab waren Hevy und Strong, die verbreiteten Apps dafür. Es gibt 296 Übungen mit Animationen, einen Assistenten für Pläne mit zwei bis sechs Trainingstagen, Aufwärmsätze und Steigerungsvorschläge, einen Pausentimer, der sich auch bei gesperrtem Handy per Push meldet, und Diagramme für Volumen, geschätztes Maximalgewicht und Körpergewicht. Wer von Hevy oder Strong kommt, nimmt seinen Verlauf als CSV mit. Volumora ist eine Web-App, die man auf dem Homescreen installiert. Sie läuft offline, kommt ohne Framework und ohne Build-Schritt aus, und jeder Merge auf den Hauptzweig ist sofort live.

Volumora is a workout app for the phone: create plans, tick off sets at the gym, see your progress. The yardstick was Hevy and Strong, the common apps for this. It has 296 exercises with animations, an assistant for plans with two to six training days, warm-up sets and progression suggestions, a rest timer that alerts you by push even on a locked phone, and charts for volume, estimated one-rep max and body weight. Anyone coming from Hevy or Strong brings their history along as CSV. Volumora is a web app you install on the home screen. It works offline, needs no framework and no build step, and every merge to the main branch is live straight away.

Wie sie gebaut wirdHow it is built

Gebaut habe ich sie mit Agenten, in Meilensteinen nach einem festen Plan: ein Branch je Meilenstein, ein Pull Request, die Pipeline muss grün sein, dann der Merge. So sind in gut fünf Wochen 56 Pull Requests zusammengekommen. Die Gestaltungsregeln stehen in einer eigenen Datei im Repository, damit jeder Agent an denselben Stil anschließt und die App nicht mit jeder Runde anders aussieht.

I built it with agents, in milestones following a fixed plan: one branch per milestone, one pull request, the pipeline has to be green, then the merge. That added up to 56 pull requests in just over five weeks. The design rules live in their own file in the repository, so every agent picks up the same style and the app does not look different after each round.

Wie getestet wirdHow it is tested

Jeder Pull Request läuft durch GitHub Actions. Die Unit-Tests prüfen die Teile ohne Oberfläche: Einheiten und Scheibenrechner, Steigerungsvorschläge, den Import aus Hevy und Strong, Sicherungen aus älteren Fassungen, die Werkzeuge des Assistenten und den Server. Die Playwright-Tests starten die echte App in Chromium und gehen die Abläufe durch, vom Training über den Plan-Editor bis zu Rückgängig, Offline-Start und einer axe-core-Prüfung auf Barrierefreiheit. Gemergt wird erst, wenn alles grün ist.

Every pull request runs through GitHub Actions. The unit tests cover the parts without a user interface: units and plate calculator, progression suggestions, the Hevy and Strong import, backups from older versions, the assistant’s tools and the server. The Playwright tests start the real app in Chromium and work through the flows, from a workout and the plan editor to undo, offline start and an axe-core accessibility check. Nothing is merged until everything is green.

Fehler, die nur das iPhone zeigtBugs only the iPhone shows

Ein Teil der Fehler tritt nur in der installierten App auf dem iPhone auf. Auf meinem Handy lag ein schwarzer Balken unter der Tab-Leiste, und beim Scrollen schimmerte der Inhalt durch die Statusleiste; in Chromium war beides nicht zu sehen. Eine Diagnosezeile in den Einstellungen hat die echten Maße vom Gerät geliefert, im iOS-Simulator ließ sich der Fehler dann nachstellen. Die Ursache: Installierte Web-Apps legen die Seite unter die Statusleiste, zeichnen gescrollten Inhalt aber trotzdem hinein. Seitdem scrollt nicht mehr das Dokument, sondern der Container der App.

Some bugs only appear in the installed app on the iPhone. On my phone there was a black band under the tab bar, and when scrolling, the content showed through the status bar; neither was visible in Chromium. A diagnostics line in the settings delivered the real measurements from the device, and the iOS simulator then reproduced the bug. The cause: installed web apps lay the page out below the status bar but still paint scrolled content into it. Since then the app’s container scrolls instead of the document.

Claude in der AppClaude inside the app

Ein Claude-Assistent hat einen eigenen Tab. Er hat 18 Werkzeuge und die Websuche: Er schlägt Trainingsdaten nach, legt Pläne an und ändert sie, passt Einstellungen und das laufende Training an. Jede Änderung steht im Chat und lässt sich dort rückgängig machen. Einen Plan löscht er nur nach einem Ja, und abgeschlossene Trainings kann kein Werkzeug ändern oder löschen. Sätze lassen sich auch einsprechen: Die Spracherkennung übernimmt das Gerät, ausgewertet wird in der App.

A Claude assistant has its own tab. It has 18 tools plus web search: it looks up training data, creates and changes plans, and adjusts settings and the running workout. Every change shows up in the chat and can be undone there. It deletes a plan only after a yes, and no tool can change or delete a finished workout. Sets can also be spoken: the device does the speech recognition, the app does the parsing.

Konten und ServerAccounts and server

Seit November gibt es Konten. Ein kleiner Node-Server auf einem Raspberry Pi hält die Daten, leitet Anfragen an Claude mit einem Monatsbudget je Konto weiter und schickt Push-Nachrichten. Den Claude-Schlüssel kennt nur der Server, nicht das Handy. Ein Konto gibt es nur mit Einladung. Neue Fassungen holt sich der Server nach grüner Pipeline selbst und geht zurück, wenn die neue Fassung nicht startet. Prepora, meine zweite App, nutzt dasselbe Konto und denselben Server.

Since November there are accounts. A small Node server on a Raspberry Pi holds the data, relays requests to Claude with a monthly budget per account and sends push messages. Only the server knows the Claude key, never the phone. Accounts are by invitation only. The server fetches new versions by itself after a green pipeline and rolls back if the new version does not start. Prepora, my second app, uses the same account and the same server.
