Diese Seite ist handgeschriebenes HTML, CSS und JavaScript, ohne Framework und ohne fremde Dienste. Wie sie entstanden ist, steht hier; was sie nicht kann, auch.

This site is hand-written HTML, CSS and JavaScript, with no framework and no third-party services. How it came about is described here, and so is what it cannot do.

Wie sie entstanden istHow it came about

Gebaut habe ich die Seite im Dialog mit einem KI-Agenten, über mehrere Wochen, in derselben Arbeitsweise wie die Projekte darauf: Ich gebe Richtung und Urteil, der Agent setzt um, prüft im Browser und legt Screenshots vor. Was mir nicht gefällt, fliegt raus. Vier Gestaltungsentwürfe wurden verworfen, einmal die gesamte Textfassung, einmal das ganze Design. Vor jedem Stand wurde jede Seite auf Desktop und Handy gerendert, die Kontraste gemessen (8,9 : 1 für den Akzent auf Dunkel, 5,2 : 1 auf Hell), alle Links geprüft und die Konsole auf Fehler durchgesehen. Jede Änderung ist ein Commit im öffentlichen Repository.

I built the site in dialogue with an AI agent, over several weeks, in the same way of working as the projects on it: I set the direction and pass judgement, the agent implements, checks in the browser and presents screenshots. Whatever I do not like goes. Four design drafts were discarded, once the entire text, once the whole design. Before every release each page was rendered on desktop and phone, the contrasts measured (8,9 : 1 for the accent on dark, 5,2 : 1 on light), every link checked and the console read for errors. Every change is a commit in the public repository.

Was die Seite nicht kannWhat the site cannot do

  • Sie misst keine Besucher. Ob jemand kommt, weiß ich nicht.
  • Die Pipeline läuft nicht wirklich. Die echten Pipelines gehören Kunden und bleiben dort.
  • Die Messung in Projekt 01 umfasst drei Wochen nach der Umstellung gegen 27 davor. Mehr Daten kommen mit der Zeit.
  • Die englische Fassung ist eine Übersetzung, kein Muttersprachler hat sie gelesen.
  • It does not count visitors. Whether anyone comes, I do not know.
  • The pipeline does not actually run. The real pipelines belong to clients and stay there.
  • The measurement in project 01 covers three weeks after the switch against 27 before. More data comes with time.
  • The English version is a translation; no native speaker has read it.
